# Data availability

This repository does not redistribute the archived raw DGHS dashboard responses.

The study used publicly accessible aggregate dashboard observations. Raw response
archives remain subject to source-accessibility and redistribution review.

The public repository provides:

- the manuscript;
- the bounded acquisition and validation tooling;
- provenance documentation;
- checksums and research-method documentation;
- the validated presentation package.

No patient-level identifiers were processed in the analyzed tables. Formal
institutional review or exemption status has not yet been determined.

Researchers should not bypass authentication, CAPTCHA, rate limits, or other
access controls when independently accessing the public DGHS interface.
